---
description: Start a new animation feature from scratch — runs the full GSD plan loop
---

Step 1: Ask the user: "What are you building? Describe the feature, what it should do, and any specific tools/libraries/frameworks you want used."
Step 2: Run /gsd-discuss-phase with the user's answer to lock in the feature decisions.
Step 3: Run /gsd-plan-phase to research and produce a build plan. Show the plan and wait for approval before proceeding.
Step 4: Once the user approves, run /gsd-execute-phase to build it.
